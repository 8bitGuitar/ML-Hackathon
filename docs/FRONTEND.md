# PathSnap frontend: what was built

The evaluator UI is a Streamlit app (`ui.py`) that runs on laptop 2. It lists the evaluation trips, sends the chosen
trip ID to the API on laptop 1 and shows the returned route on a map with the scores. It holds no data or model of its
own, so the true route never reaches it.

## Files

| File | Role |
|---|---|
| `ui.py` | The whole UI: sidebar, API calls, metric cards and map |
| `config.py` | Supplies the default API address (`PATHSNAP_API_URL`); shared with the backend |

Laptop 2 needs only these two files plus `streamlit`, `folium` and `requests`.

## What the evaluator sees

**Sidebar**
- **API address:** a text box, pre-filled from `PATHSNAP_API_URL` (default `http://localhost:8000`). Change it to
  `http://<laptop 1 IP>:8000` without restarting.
- **Connection status:** a green "Connected: 10 trips" message, or a red error naming the address that failed.
- **Reload trips:** fetches the list again, for example after laptop 1 restarts.
- **Evaluation trip:** a dropdown filled from `GET /trips`.
- **Run prediction:** sends the selected trip to `POST /predict`.

**Main area**
- **Metric cards:** accuracy, route continuity, route F1 and number of GPS fixes. Hovering over a card explains the
  metric. An "All scores" expander shows the full JSON from the API.
- **Map:** a Folium map (OpenStreetMap tiles) fitted to the trip. The predicted route is a blue line with start and
  end markers, and the GPS fixes are red dots. A layer control toggles the fixes.

## How it talks to the API

| Step | Call |
|---|---|
| Page load or "Reload trips" | `GET <api>/trips` |
| "Run prediction" | `POST <api>/predict` with `{"trip_id": "<id>"}` (120 s timeout) |

The response holds `metrics`, `route` (a `[lat, lon]` polyline), `track` (the GPS fixes), `route_arcs` and `seconds`.
The result is kept in the Streamlit session, so it stays on screen when the sidebar changes.

If the API is unreachable, the sidebar shows the error and the Run button is disabled. If a prediction fails, the
main area shows the error instead of a map.

## Design choices

- **Streamlit:** fastest way to a working UI in Python, with no separate JavaScript build.
- **Folium embedded with `st.iframe`:** `streamlit-folium` did not install, and this needs no extra package. The map HTML
  is generated by our own code, never from user input.
- **Configurable address:** the API IP is only known on the day, so it is both an environment variable and a sidebar
  field.

## Running it

```
PATHSNAP_API_URL=http://<laptop 1 IP>:8000 .venv/bin/streamlit run ui.py
```

It opens at `http://localhost:8501`. To let other devices open the UI, add `--server.address 0.0.0.0`.

## Verification

Tested with Streamlit's `AppTest` against the live API: the trip list loads, selecting a trip and pressing Run shows
the metrics (trip `00000077`: accuracy 84.28%, continuity 100%, route F1 97.84%), and the values match the API log.
The map has not been checked by eye in a browser, and the UI has not been run from a second machine yet.
